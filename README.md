## 📁 Using userjs-forge

Once you have installed userjs-forge, you can start managing your userscripts.

1. **Create a New Userscript**
   - Open userjs-forge from your applications or start menu.
   - Click on the "Create Script" button to begin.
   - Fill in the required details such as script name and description.

2. **Manage Existing Userscripts**
   - From the main interface, you can view all your existing scripts.
   - Click on any script to edit or delete it.

3. **Release Your Userscripts**
   - Once your script is ready, find the "Release" option.
   - Choose to package your script and share it with others by following the prompts.
